# Languages

Pick the language in `market.md`. Write it only after you open this file. A speaker of that language reads the lines aloud before anyone shoots. The samples below are a register check, not a finished film.

Hinglish is a fluent urban mix. It is the wrong default for a rural film, a high-trust category (health, money, school, property), or a state occasion such as Onam, Pongal, or Durga Puja.

Do not write mock pidgin. The bad line in `craft.md` is a private check. It never goes in the script.

## When the language is already chosen

| Language | Where it is the film | A standard line for "the guests have arrived" |
| --- | --- | --- |
| Hindi | Hindi belt, unless the brief asks for Hinglish | मेहमान आ गए। |
| Hinglish | Urban social and many D2C brands, when the audience already talks this way | Mehmaan aa gaye. |
| Tamil | Tamil Nadu. Not Hinglish with a Tamil word added | விருந்தினர் வந்துட்டாங்க. |
| Telugu | Andhra Pradesh and Telangana | అతిథులు వచ్చేశారు. |
| Kannada | Karnataka | ಅತಿಥಿಗಳು ಬಂದಿದ್ದಾರೆ. |
| Malayalam | Kerala, including Onam | അതിഥികൾ എത്തി. |
| Marathi | Maharashtra, including Ganesh Chaturthi at home | पाहुणे आले. |
| Bengali | West Bengal, including Durga Puja | অতিথিরা এসে গেছেন. |
| Gujarati | Gujarat, including Navratri | મહેમાન આવી ગયા. |
| Punjabi | Punjab, including Lohri and Baisakhi | ਮਹਿਮਾਨ ਆ ਗਏ. |

Use the script of that language on screen. An English disclaimer on a Tamil film does not count as the disclosure. The disclosure rule is in `compliance.md`.

Odia, Assamese, and other languages follow the same rule: write in that language, or mark the lines `Missing` and ask. Do not pass Hinglish off as the state language.

Mumbai, Hyderabad, and Bengaluru are more than one language. Leave the language `Missing` until the brief picks.

Under every audience-facing line, add the English working translation when the user is working in English. Do not replace the spoken line with the translation.
